A modern, highly responsive, and interactive personal developer portfolio built for **Vaidon Shello Sinambela** (IT Developer & UI/UX Enthusiast).

---

## ✨ Features

- 🎯 **Hero Section**: Terminal-style interactive JSON card, dynamic typing role effect, and social connectivity.
- ⚡ **Interactive Services & Metrics**: Live animated stats counter, interactive service cards with hover glow and spotlight effects.
- 📁 **Filterable Project Showcase**: Category filtering (Web, UI/UX, AI, Mobile) with animated cards, tags, and direct preview modals.
- 🛠️ **Skill Inventory**: Interactive tabs categorized into Frontend, Backend, UI/UX Design, and Tools with proficiency indicators.
- 💬 **Testimonials Carousel**: Endorsements and recommendations with dynamic navigation controls.
- 📬 **Interactive Contact Form**: Direct form submission handling with real-time field validation, feedback modal, and social connection points.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays with accessible semantic HTML5.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, ES6+ JavaScript
- **Styling**: Modern CSS Grid/Flexbox + Tailwind CSS (v3 CDN)
- **Typography**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono
- **Icons**: FontAwesome 6, Devicon

---

## 💻 Local Preview

To run this portfolio locally on your machine:

```bash
# Clone the repository
git clone https://github.com/selosinambela/selosinambela.github.io.git

# Navigate to the folder
cd selosinambela.github.io

# Open index.html in your preferred browser
start index.html
```
